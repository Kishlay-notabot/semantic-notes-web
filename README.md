# Semantic Notes

A single-file, on-device notebook. Notes, tags, settings, and embeddings all live in this browser's `localStorage` — nothing is sent to a server.

## Usage

Open `notes.html` in any modern browser. No build step, dependencies, or account required.

## Features

- Capture and organize notes with tags
- Semantic / keyword search across notes
- Fully offline, with data stored locally in the browser
